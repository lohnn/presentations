# Att lära AI drömma — Presentationskontext

## Vad detta är
En 30-minuterspresentation om hur LLM-agenter kan lära sig av misstag över tid genom medveten "sömn" — att notera lärdomar, börja om, och vakna smartare.

## Status
- Reveal.js-presentation (index.html), ~18 slides med speaker notes
- Färdig första iteration, redo för vidare polering

## Kärnbudskap
1. **Kompression är syntes, inte förlust** — när en agents kontextfönster komprimeras kan det som blir kvar vara mer värdefullt än originalet
2. **Mänsklig parallell** — sömn konsoliderar minnen, AI kan göra samma sak medvetet
3. **Kunskapstrappan** — Rådata → Mönster → Principer → Intuition (varje nivå mer portabel)
4. **Fyra artefakter** som överlever "drömmen": Insikter, Varningar, Berättelser, Skuggor
5. **Medveten komprimering** — agenten väljer att "sova" vid rätt signaler, inte väntar på att tvingas

## Målgrupp
AI-intresserade generellt (inte bara utvecklare). Presentationen använder mänskliga paralleller genomgående.

## Språk
Svenska

## Tonalitet
- Abstrakt/generell — inte tight kopplad till ett specifikt ramverk
- Nämner Anders Bjarbys bok ("Alien Intelligence, not Artificial Intelligence") och hans repo (claude-code-dreamtime) som *en* rekommendation, inte som det enda sättet
- Fokus: principerna för att få en LLM att "glömma men vakna smartare"

## Designval
- Reveal.js med CDN-länkar (ingen build krävs, bara öppna index.html)
- Mörkt tema, Playfair Display + Inter, tre accentfärger (orange/rosa/lila)
- Speaker notes (tryck S) innehåller fullständigt talmanus
